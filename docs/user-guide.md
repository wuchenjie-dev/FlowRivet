# FlowRivet 普通用户操作指导手册

## 1. FlowRivet 是什么

FlowRivet 是运行在 Codex 中的个人工作看板。当前版本默认连接飞书项目，读取当前飞书账号分配给你的工作项，并按“待处理、进行中、待验收、已完成”展示。

当前看板为只读模式：你可以查看、筛选、刷新和打开飞书原始工作项，但不能在看板中修改状态、负责人或排期。

普通用户不需要配置飞书应用的 `Client ID`、`Client Secret`、个人 Token 或远程 MCP 地址。登录由本机飞书项目 CLI 和系统浏览器完成，FlowRivet 不接收你的飞书密码。

## 2. 使用前准备

开始前请确认：

- 已安装 Codex 桌面应用，并已安装和启用 FlowRivet 插件。
- 已通过团队提供的 FlowRivet 安装器完成一次安装。安装包自带私有 Node.js，不要求系统安装 Node、Git 或 npm。
- 当前飞书账号可以访问飞书项目，并且至少有查看个人工作项的权限。
- 组织网络允许访问 `project.feishu.cn`。

如果 Codex 中尚未安装 FlowRivet，请先联系团队维护人员获取并安装插件。当前版本没有面向普通用户的公共应用商店安装入口。

首次使用还需要安装官方飞书项目 CLI。在 PowerShell、Terminal 或其他终端中运行：

```powershell
npx -y @lark-project/meegle@latest install
meegle config set host project.feishu.cn
```

安装完成后回到 FlowRivet，点击“重新检查飞书项目连接”。普通用户不需要在终端中填写密码或 Token。

## 3. 打开我的待办看板

1. 打开 Codex，新建一个任务。
2. 输入“打开我的待办看板”或“打开我的飞书项目待办”。
3. Codex 调用 FlowRivet 后会显示看板。
4. 看板会尝试全屏展开；如果没有自动全屏，点击右上角的全屏图标。

FlowRivet 当前通过对话中的固定任务打开看板。Codex 暂不支持由插件在应用侧边栏永久增加独立菜单。

## 4. 首次连接飞书项目

首次打开时，页面会显示“连接飞书项目后查看我的待办”。

1. 点击“连接飞书项目”。
2. FlowRivet 会打开系统默认浏览器。
3. 在飞书授权页面确认账号和权限，然后点击“授权”。
4. 授权成功后关闭浏览器页面，回到 Codex。
5. FlowRivet 会自动确认账号并加载任务，不需要复制授权码，也不需要点击“检查授权结果”。

如果浏览器没有自动打开，页面会显示“打开临时授权页”和备用授权码。只有出现该提示时，才需要使用临时入口和备用码。

授权等待超过 15 秒并不表示失败。只要页面显示“仍在等待飞书确认”，本次授权仍然有效。完成浏览器中的确认后，FlowRivet 会自动继续。

## 5. 看懂任务看板

### 看板分栏

- **待处理**：尚未开始的工作项。
- **进行中**：正在处理或开发的工作项。
- **待验收**：处于评审、测试或验收阶段的工作项。
- **已完成**：最近完成的工作项。完成数据从最后成功同步起最多保留 7 天。

### 任务卡片

任务卡片可能显示：

- 工作项类型，例如需求、任务或缺陷。
- 飞书项目工作项 ID。
- 工作项标题。
- 所属项目。
- 截止日期。只有飞书工作项设置了排期时才会显示。

### 左侧筛选

- **全部待办**：显示当前同步到的所有工作项。
- **即将到期**：显示未来 7 天内到期的工作项。
- **已逾期**：显示截止时间早于当前时间的工作项。
- **项目名称**：只显示所选项目的工作项。

## 6. 打开飞书原始任务

点击任务卡片后，FlowRivet 会在浏览器中打开对应的飞书项目详情页。

如果出现“工作项链接无效，无法打开”：

1. 先点击右上角刷新按钮重新同步。
2. 确认当前飞书账号仍有权访问该项目和工作项。
3. 确认 Codex 已重启并加载最新版本的 FlowRivet。
4. 仍无法打开时，将任务 ID、发生时间和页面提示提供给 FlowRivet 维护人员；不要提供密码、Token 或授权码。

## 7. 刷新任务

### 手动刷新

点击右上角刷新图标，立即从飞书项目重新读取任务。刷新会清除当前会话中的任务详情缓存，但不会退出飞书账号。

### 自动刷新

点击右上角账号区域打开连接菜单，在“自动刷新”中选择：

- 不自动刷新
- 每 5 秒
- 每 10 秒
- 每 30 秒
- 每 60 秒
- 自定义 5 至 3600 秒

页面处于后台或不可见时会暂停自动刷新。飞书限流或登录失效时也会暂停；重新连接成功后恢复。

## 8. 连接状态和离线数据

看板右上角显示当前 Provider、连接状态和最后同步时间。

- **已连接**：可以从飞书项目同步数据。
- **需重新登录**：本机飞书会话已经失效，需要重新授权。
- **离线数据**：当前同步失败，但 FlowRivet 正在展示最近一次成功同步的摘要。

离线缓存只保存看板需要的任务摘要，不保存飞书密码、登录凭据、评论、附件或上游响应正文。缓存从最后一次成功同步起保留 7 天，超过 7 天后自动删除。

连接恢复后点击刷新按钮，即可切回实时数据。

## 9. 测试本地 Companion

点击右上角账号区域，在连接菜单中选择“测试本地 Companion”。

- 显示“本地 Companion 已响应”：本地服务正常。
- 显示“本地 Companion 无法访问”：FlowRivet 本地服务未启动或端口不可用，请联系维护人员处理。

Companion 只监听本机地址，不需要也不应暴露到公网。

## 10. 工作项通知

FlowRivet Companion 在本机运行期间，默认每 60 秒检查一次当前已连接飞书账号的个人工作项。首次检查只建立基线，不会把现有任务集中弹出；之后会提醒新分配、状态变化、排期变化、24 小时内到期和已逾期。

看板右上角铃铛显示未读数量。点击铃铛可以查看最近 30 天通知、逐条打开飞书原任务或全部标记已读。系统弹窗只负责提醒，打开任务请使用看板通知中心。

通知按飞书账号隔离，本地只保存任务标题、项目、变化摘要、时间和经过校验的链接，不保存凭据、描述、评论或附件。30 天后自动删除；关闭 Companion 后不会继续扫描。

MCP 不能主动唤醒 Codex 或创建 Codex 桌面消息。需要在 Codex 对话中定时汇总时，应另外配置 Codex Automation 调用只读通知工具。

## 11. 退出或切换飞书账号

1. 点击右上角账号区域。
2. 点击“断开飞书项目”。
3. 看板清除当前 Provider 的活动缓存并返回连接页面。
4. 再次点击“连接飞书项目”，在浏览器中使用目标账号授权。

如果飞书授权页面仍自动使用旧账号，请先在浏览器中退出飞书项目账号，再重新发起连接。

## 12. 更新 FlowRivet

FlowRivet Companion 会在用户登录后启动，并从企业内部 GitLab 安全检查更新。更新包通过大小、SHA-256、协议、归档布局和健康检查后自动启用；失败时自动恢复上一版本。

### 普通用户更新流程

1. 正常使用看板，无需手动下载或覆盖文件。
2. 页面显示“新版已就绪”后，点击“复制重新打开指令”。
3. 在 Codex 对话中发送“重新打开 FlowRivet 看板”。
4. 只有重新打开后仍显示旧页面时，才完全退出并重启 Codex。

### 源码方式安装的用户

如果你持有 FlowRivet 源码，可在仓库根目录运行：

```powershell
npm run plugin:update
```

需要同时从当前分支的上游获取最新提交时运行：

```powershell
npm run plugin:update -- --pull
```

该命令属于开发者工作流，不是普通用户的更新方式。

## 13. 常见问题

### 页面提示未检测到飞书项目 CLI

运行：

```powershell
npx -y @lark-project/meegle@latest install
```

安装后点击“重新检查飞书项目连接”。

### 浏览器没有弹出授权页面

等待页面显示手动入口，然后点击“打开临时授权页”。不要从日志中寻找或复制授权参数。

### 浏览器显示授权成功，但看板没有变化

返回 FlowRivet 等待自动确认。如果仍未变化，点击“重新检查连接”。不要重复输入验证码或重新安装 CLI。

### 授权完成，但任务同步失败

飞书账号连接可能仍然有效。先点击看板刷新按钮重试，不需要立即重新授权。

### 看板没有任务

- 确认飞书项目中的工作项已分配给当前账号。
- 确认工作项属于 FlowRivet 当前读取的个人待办范围。
- 检查左侧是否选择了项目或“即将到期”“已逾期”等筛选项。
- 断开后重新连接飞书项目，确认使用的是正确账号。

### 任务没有截止时间

FlowRivet 读取飞书项目工作项排期的结束时间。飞书原任务未设置排期时，看板不会显示截止日期。

### 点击任务提示链接无效

先手动刷新，再确认已重启 Codex 并新建任务以加载最新版插件。如果飞书原任务已删除、项目地址已变更或当前账号没有访问权限，也可能无法打开。

### 页面显示旧版本

先在对话中发送“重新打开 FlowRivet 看板”。只有宿主仍缓存旧页面时才重启 Codex。

### 页面显示离线数据

这是同步失败时的只读降级。检查飞书连接和本地 Companion，再点击刷新；缓存超过 7 天后会自动删除。

## 14. 安全注意事项

- 不要把飞书密码、Token、授权码、`Client Secret` 或系统钥匙串内容发到 Codex 对话中。
- 不要把凭据写入仓库、截图、日志或工单。
- 普通用户不需要企业飞书应用密钥，也不需要部署远程 MCP 服务。
- 只在系统浏览器中的官方 `project.feishu.cn` 页面完成飞书授权。
- FlowRivet 当前看板为只读，不会修改飞书项目中的工作项。

## 15. 获取支持时提供什么

遇到问题时，请提供：

- 操作系统和 Codex 版本。
- FlowRivet 页面上的错误提示。
- 问题发生的大致时间。
- 是否可以通过“测试本地 Companion”。
- 是否能在浏览器中直接打开飞书项目。
- 相关工作项 ID；敏感项目可先脱敏。

请勿提供密码、Token、授权码、Client Secret、完整业务数据或内部仓库地址。
